# serial-snap

forTUNE meets（ticket.fortunemeets.app）の抽選応募のシリアルナンバーを、紙を撮影するだけで読み取る非公式ツール「シリアルスナップ」です。
読み取ったシリアルナンバーは応募先ごとにまとまり、10件ずつコピーして、付属のブックマークレットで応募サイトの入力欄へ入れられます。

- **写真もシリアルナンバーも端末の外へ送りません。** 文字認識はブラウザの中（WebAssembly）で動き、結果はその端末にだけ保存します
- 1枚の写真に何枚の紙が写っていても、紙の向きがバラバラでも読み取れます
- 紙のQRコードや印刷された応募サイトのURLから、応募先ごとにまとめます
- シリアルナンバーごとに写真の切り抜きを並べるので、読み違いがないか目で確かめられます
- スキャンは1回ごとに30日間残り、あとからコピーし直せます
- 一度開けば通信なしでも使えます

公開先: https://serial-snap.yabworks.com/

非公式のツールです。応募サイトの運営者とは関係ありません。

## 使い方

1. シリアルナンバーの紙を並べて撮るか、撮ってある写真を選びます（続けて何枚でも撮れ、まとめて選べます）
2. 写真の切り抜きと読み取った文字を見比べ、違っていれば修正します
3. 「1〜10件目をコピー」を押します
4. 応募サイトのシリアルナンバー登録の画面でブックマークレットを開き、「クリップボードから入力」を押します
5. 入力欄の内容を確かめて、「シリアルナンバー登録」をご自身で押します

ブックマークレットは入力欄へ値を入れるだけで、登録ボタンは押しません。
応募サイトは登録の失敗が続くとアカウントを一時停止するため、登録の前に必ず紙と見比べてください。
ブックマークレットの追加方法は、アプリのメニューの「ブックマークレットの追加」で端末ごとに案内しています。

## 開発

Node.js 24 以上が必要です。

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ に出力
npm run preview    # http://localhost:4173（Service Worker は本番ビルドでのみ動く）
npm test
npm run lint
npm run eval:ocr   # .local/fixtures/ の写真で読み取りを試す
npm run icons      # public/icon.svg からホーム画面用のアイコンを作り直す
```

開発の指針は [AGENTS.md](AGENTS.md)、設計は [docs/](docs/) にあります。
実物のシリアルナンバーが写った写真は `.local/` に置き、Git に入れないでください。
