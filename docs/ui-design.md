# UI設計

画面の設計は [デザインのキャンバス](https://claude.ai/artifact/S3tpgEZQcgMsac3Cjbvzoj) にある。ここには実装で守る方針と、キャンバスから変えた点をまとめる。

ITに詳しくない人が、初めてでも迷わずに「撮る → 確かめる → コピー → 貼り付け」まで進めることを優先する。

## 共通

- ヘッダーは上、操作の帯は下端に固定し、その間だけをスクロールさせる（[アーキテクチャ](architecture.md#画面の骨組み)）。
- 画面はスマホに合わせて作る。PCでも同じ1列の画面を中央に出す（最大560px）。PC向けの配置（キャンバスのPC版）は作らない。ヘッダーと帯は端から端まで色を敷き、中身だけを列に揃える。
- 地と文字は無彩色、基調色は深い緑（明るいテーマ `#1D5C42`、暗いテーマはボタンの地 `#2A6F50`・文字 `#A3CDB6`）。色の値は `panda.config.ts` を正とする。応募サイトのミント色（`#1CD0AC`）とは明るさも鮮やかさも違える。公式と間違われないため。
- 基調色を使うのは、主なボタン・選んでいる応募先とページのタブ・「送りません」の帯・コピー済みの印だけ。
- 失敗・注意・完了は、色だけでなくアイコンと文字でも示す（赤と緑を見分けにくい人のため）。
- テーマは「端末に合わせる／明るい／暗い」をメニューで選ぶ。既定は端末に合わせる。選んだテーマは `<html>` の `data-theme` に置き、ブラウザの上部の色（theme-color）もヘッダーの地の色に揃える。
- シリアルは IBM Plex Mono（0に点が入り、Oと見分けられる）。本文は端末の書体。
- タップ領域は44px以上、入力欄の文字は16px以上（iPhoneの自動ズームを防ぐため）。
- アイコンは線のSVGを使い、UIの飾りに絵文字を使わない。
- 動きは `prefers-reduced-motion` で止める。

## 振る舞い

- 「貼り付けにはブックマークレットを使います」は、最初のコピーのときに1回だけ出す。「追加済み」を押すか、追加方法の最後のステップでブックマークレットが動いたら、以後出さない。
- ブックマークレットの名前は自由に付けてよい。案内では「追加したブックマークレット(例：シリアルスナップ)」と書く。パネルの題もアプリ名「シリアルスナップ」にする。
- 「貼り付けにはブックマークレットを使います」を出している間は、コピーしたときの知らせ（トースト）を出さない（重なるため）。
- 追加方法のステップ1で「プログラムをコピー」を押してコピーできたら、「コピーしました」を短く見せて次のステップへ進む。
- コピーの前に確認を求めない。注意のあるシリアルは行の色・アイコン・理由で目立たせ、修正すると注意が消える。

## 言葉づかい

- 簡潔にする。説明は1〜2文までにする。
- 改行を入れるのは、説明文の文と文の間だけにする。見出しやボタンなど短い文の途中では改行しない（狭い画面で折り返すときは、文節の区切りで折り返す `word-break: auto-phrase` を使う）。
- 漢字で書く言葉は漢字で書く（試して・必ず・間違える・詳しく・最初に）。
- ラベル・状態・ボタンは体言止めか短い動詞（スキャン中・完了・コピー済み・保存・削除）。説明は「です・ます」。
- 「〜だけ」ではなく「〜のみ」（初回のみ・一度のみ）。
- 括弧は半角、日付は `10月11日(日) 21:40`。
- 確認ダイアログの取り消しは「キャンセル」。削除の確認には、何が消えるかと「元に戻せません。」を書く。
- 画面の用語は「シリアルナンバー」（略さない）「スキャン」（利用者がすることと、その1回分の記録）「読み取り」（アプリが写真の文字を読む処理とその結果）「応募先」「応募サイト」「コピー」「修正」「ブックマークレット」。

## あとで作るもの

- **トップのキャッチコピー**：「シリアルナンバーをまとめて読み取り」は見た目が弱いため外した。デザイン性のある見せ方を考えてから加える。

## キャンバスから変えた点

キャンバスを確定したあとに決めた修正。実装ではこちらに従う。

- コピー後の下端の帯は「再コピー」と「応募サイトを開く」の2つにする（「⋯」メニューに隠さない）。
- 「ホーム画面に追加」の案内は作らない（メニューの項目とトップの案内も出さない）。応募サイトのためにブラウザを開くことになり、アプリとして開く利点が小さいため。通信なしで使えるようにする仕組み（Service Worker）と、自分で追加したときの名前とアイコンは残す。
- ホーム画面に追加したとき、アイコンの下に出す名前（manifestの `short_name`）は、半角カナの「ｼﾘｱﾙｽﾅｯﾌﾟ」にする。全角の「シリアルスナップ」は途中で切れやすいため。
- 応募先が1つのときは、読み取り結果の応募先の切り替えを出さない。
- ブックマークレットは、開いただけではクリップボードを読まない。「クリップボードから入力」を押したときだけ読む（Safariは押した直後でないと読ませず、開いた瞬間の読み取りはうまく動かなかった。ほかのブラウザでも開くたびに確認が出るのは不便なため）。貼り付けた瞬間に入力する形は取らない（入力の途中で動かないように、入力欄と「入力」のボタンの形を崩さない）。
- ブックマークレットのパネルの応募先は「nogizaka46」のようにURLのアーティスト部分だけを出す（グループ名との対応表は持たない）。
- 応募先の違いの見出しは「応募先が違う可能性があります」、本文は「まだ入力していません」。
- 「一度だけ」は「一度のみ」に揃える。
- 使い方の「応募サイトで貼り付け」は、ブックマークレットを開いたあと「クリップボードから入力」を押すことまで書く（パネルが押したときだけ読むようにしたため）。
- 使い方・追加方法の図は、すべてアニメーションで作る（実際の画面の録画には差し替えない）。
