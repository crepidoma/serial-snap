# 製品要件

## 目的

forTUNE meets（ticket.fortunemeets.app）の抽選応募のシリアルナンバーを、紙を撮影するだけで読み取り、応募先ごとにまとめる非公式ツール。まとめたシリアルナンバーを10件ずつコピーし、ブックマークレットで応募サイトの入力欄へ貼り付けられるようにする。

## 利用者

- 何十枚もシリアルナンバーの紙を持っていて、手で打ち込むのが大変な人。
- ITに詳しくない人も多い。スマートフォン（iPhone 11以降・最近のAndroid）が中心で、PCの人もいる。

## 約束すること

- **写真もシリアルナンバーも端末の外へ送らない。** 読み取りは端末の中だけで行う。トップと読み取り結果の上部に常に書く。
- 応募サイトの登録ボタンは押さない。入力欄へ入れるまでを手伝い、確かめて押すのは利用者。
- 非公式であること、読み取りの誤りに責任を負えないことは「このアプリについて」に書く。

## 機能

| 機能 | 内容 |
| --- | --- |
| 読み込み | 写真を複数枚まとめて選ぶ、またはカメラで撮る。1枚に何枚の紙が写っていてもよく、紙の向きはバラバラでよい。 |
| 読み取り | 紙のシリアルナンバーと、応募サイトのリンク（QRコード、または紙に印刷されたURL）を読む。縦にずらして重ねた紙ではURLが隠れ、QRコードだけが見えるため、両方を読む。 |
| 応募先の束ね方 | 応募サイトのリンクのアーティスト部分ごとに束ねる。リンクが読めない紙は、写真の中のリンクが1種類ならそれに入れる。決められなければ「応募先不明」に入れる。 |
| 確認・修正 | シリアルナンバーごとに写真の切り抜き（上）と読み取った文字（下）を並べる。確信度が低い・桁数がほかと違う・英数字以外を含む・ほかのスキャンにもある（登録済みの可能性）ものは色と理由で目立たせる。修正・削除ができる。手入力での追加は持たない（応募サイトへ直接入れればよいため）。 |
| コピー | 10件ずつのページごとにコピーする（応募サイトが一度に10件まで受け付けるため）。1件ずつのコピーもできる。コピー済みの印を付ける。 |
| ブックマークレット | 応募サイトのシリアルナンバー登録の画面で開くと、アプリでコピーしたシリアルナンバーを、「クリップボードから入力」を押したとき（または手で貼り付けて「入力」を押したとき）に入力欄へ入れる。足りない入力欄は「入力枠を追加」を押して増やす。桁数の違い、開いているページとコピーした応募先の違いを知らせる。 |
| 履歴 | 写真を選ぶたびに新しいスキャンとし、今回読み取ったシリアルナンバーはすべて結果に出す（同じスキャンの中の重複だけをまとめる）。スキャン1回ごとに、日時・応募先ごとの件数・シリアルナンバー・切り抜き・コピーの進み具合を端末に残す。30日で自動的に削除する。1件ずつ、またはメニューからすべて削除できる。写真そのものは残さない。 |
| 使い方 | 初めての人にはトップから、それ以外はヘッダーの「？」とメニューから、使い方・ブックマークレットの追加方法（端末ごと）・貼り付けの手順を見られる。 |
| オフライン | 初回に一度開けば、2回目からは通信なしで使える。ホーム画面への追加は案内しない（自分で追加すれば、アプリの名前とアイコンで開ける）。 |

## 対象外

- 応募サイトへの自動登録、応募サイトへのログインの代行。
- サーバーへの保存、端末間の同期。
- 応募先の作成・名前の変更・統合、紙のタイトルによる振り分け。
- PC向けの画面の配置（PCでもスマホと同じ1列の画面を出す）。
- 手書きのシリアルナンバー。
